# 🎲 SJL 보드게임

온라인 실시간 멀티플레이어 보드게임 사이트. 방 코드만 공유하면 바로 같이 플레이할 수 있습니다.
**7개 게임 전부 Three.js 실시간 3D**로 렌더링됩니다 — 펜던트 조명 아래 원목 테이블 위에 실제 판·말·카드가 놓인 모습.
드래그로 회전, 휠/핀치로 확대, 말·카드·타일은 3D로 직접 클릭합니다.

### 3D 그래픽
- **렌더링**: ACES 필믹 톤매핑, 룸 환경맵 반사(IBL), 따뜻한 스포트라이트 + 부드러운 그림자, 클리어코트 칠
- **재질은 전부 코드로 생성**(이미지 파일 없음): 이음매 없는 나뭇결(메이플·월넛·카야·회양목·흑단), 펠트, 조개껍질 무늬, 카드 인쇄면
- **체스**: 좌표가 새겨진 상감 원목 판, 선반으로 깎은 스톤턴 기물(회양목/흑단, 펠트 받침), 호를 그리는 이동, 잡힌 말은 판 옆으로
- **바둑**: 카야 판, 양면 볼록한 흑돌·조개 흰돌, 돌이 담긴 바둑통과 사석을 담는 뚜껑, 계가 시 집 표시
- **오델로**: 금색 상감 테두리의 초록 판, 두꺼운 양면 원반이 **물결처럼 순서대로 뒤집힘**, 옆에 쌓인 원반 더미
- **다빈치 코드**: 세워 둔 타일(내 숫자만 보임), 맞히면 앞으로 넘어져 공개, 가운데 더미에서 색 골라 뽑기
- **할리갈리**: 황동 종(누르면 흔들리고 울림), 과일 그림 카드가 덱에서 뒤집혀 더미로
- **우노**: 손에 든 부채꼴 카드(낼 수 있는 것만 떠오름), 상대의 뒷면 부채, 현재 색으로 빛나는 방향 고리
- **루핑 루이**: 잔디 트레이, 탑과 팔, 조종사가 탄 복엽기(프로펠러 회전), 색깔 헛간과 닭 동전, 튕기는 레버
- 나무 톡·바둑돌 딱·카드 스침·종소리 등 **효과음도 합성**(🔊 버튼으로 끄기)
검색엔진에는 노출되지 않도록 설정되어 있습니다(배포 전용, 비공개 링크 공유).

## 지원 게임

| 게임 | 인원 | 구현된 규칙 |
|---|---|---|

| ⚫ 바둑 | 2인 | 9·13·19로, 따냄, 자살수 금지, 패(위치 초구) 금지, 두 번 패스 후 사석 표시 → 중국식 집계가(덤 6.5) |
| ⚪ 오델로 | 2인 | 8×8 정식 리버시, 8방향 뒤집기, 강제 패스, 최종 집계 |
| 🔢 다빈치 코드 | 2~4인 | 검정/흰색 0~11 + 조커, 오름차순 정렬(동수는 검정 우선), 적중 시 계속 추측/턴 종료 선택, 실패 시 뽑은 타일 공개, 더미 소진 시 자기 타일 공개 |
| ✈️ 루핑 루이 | 2~4인 | 실시간. 서버 33ms 틱 권위 판정, 레버 타이밍(230ms)·재장전(520ms), 격추 시 반대 방향 + 가속, 닭 3마리 |
| 🔔 할리갈리 | 2~6인 | 56장 정식 덱(과일 4종 × 1·2·3·4·5), 순서대로 뒤집기 + 실시간 종, 같은 과일 정확히 5개일 때만 정답, 오답 시 1장씩 지불 |
| 🃏 우노 | 2~6인 | 정식 108장 덱, 색/숫자/기호/와일드 매치, 스킵·리버스(2인은 스킵)·드로우2·와일드·와일드 드로우4, 뽑고 즉시 내기, UNO 외치기(미선언 시 잡기 +2), 손패 비우면 승리 |

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

## 테스트

```bash
npm test           # 규칙 엔진 단위 테스트 + 소켓 E2E
npm run test:browser   # 실제 Chromium 2개 창으로 7게임 전부 3D 클릭 플레이
```

`test:browser`는 Playwright를 사용합니다. 시스템에 설치된 크로미움 경로를 쓰려면
`CHROMIUM_PATH=/path/to/chrome npm run test:browser`.

## 구조

```
server.js            Express + Socket.IO. 방/좌석/관전/재접속/채팅, 서버 권위 상태
games/<id>.js        순수 규칙 엔진. create() / view(state, seat) / move(state, seat, action) / tick()
public/js/app.js     로비 + 방 셸
public/js/three3d/   scene.js(무대·조명·카메라·트윈) textures.js(절차적 텍스처) pieces.js(체스 기물)
                     cards.js(카드·타일 인쇄면) sound.js(합성 효과음) ui.js(모달·HUD)
public/js/games/     게임별 렌더러 (같은 render(state, seat) 인터페이스, 3D/2D 혼용)
public/vendor/       three.module.js (r160) + addons(RoomEnvironment, RoundedBoxGeometry), import map으로 로드
test/                엔진 · 소켓 · 브라우저 테스트
```

핵심 설계: **모든 규칙 판정은 서버에서만** 합니다. 클라이언트는 `view(state, seat)`가 돌려준
좌석별 화면만 그리므로, 다빈치 코드의 상대 타일이나 할리갈리의 뒷면 카드는 애초에 전송되지 않습니다.

## 조작

- 체스·오델로·바둑: 클릭. 바둑은 두 번 패스하면 계가 모드에서 죽은 돌을 클릭해 표시.
- 다빈치 코드: 더미에서 색 골라 뽑기 → 상대 타일 클릭 → 숫자 선택 → 추측. (타일 색은 원래 게임처럼 모두에게 보입니다)
- 할리갈리: `F` 또는 내 덱 클릭으로 뒤집기, `Space` 또는 종 클릭으로 종 치기.
- 우노: 떠오른 카드 클릭(와일드는 색 선택), 덱 클릭으로 뽑기, 1장 남으면 UNO 버튼.
- 루핑 루이: `Space` 또는 내 헛간 클릭으로 레버 치기.

모든 게임 화면은 **드래그로 시점 회전, 마우스 휠/두 손가락으로 확대/축소**할 수 있습니다.
WebGL2를 지원하는 브라우저면 별도 설치 없이 동작합니다.
